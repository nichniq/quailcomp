# Store Tests

Unit tests for Pinia stores.

## Files

- [auth.test.ts](auth.test.ts) - Authentication store tests
- [books.test.ts](books.test.ts) - Books store tests

## Overview

These tests verify Pinia store functionality including:

- State initialization
- Actions and mutations
- Computed properties
- API integration (mocked)
- localStorage persistence

See [../README.md](../README.md) for test setup and running instructions.
