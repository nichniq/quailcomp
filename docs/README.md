# Documentation

Comprehensive project documentation organized using the [Diátaxis framework](https://diataxis.fr/).

## Structure

- [**tutorials/**](tutorials/) - Learning-oriented guides that teach by doing
- [**how-to/**](how-to/) - Task-oriented guides for accomplishing specific goals
- [**explanation/**](explanation/) - Understanding-oriented articles explaining concepts
- [**reference/**](reference/) - Information-oriented technical specifications

## Quick Start

New to the project? Start here:

1. [Development Setup](how-to/setup-development.md) - Get your environment running
2. [Running Tests](how-to/run-tests.md) - Learn the test workflow
3. [Event Sourcing](explanation/event-sourcing.md) - Understand the architecture

## Finding Documentation

**I want to learn...**
