# How-To Guides

Task-oriented guides for accomplishing specific goals in the Quailcomp project.

## Purpose

These guides answer "How do I...?" questions with step-by-step instructions. They assume you understand the basics and want to accomplish a specific task.

## Available Guides

### Development Environment

- [Setup Development](setup-development.md) - Set up your local development environment
- [Run Tests](run-tests.md) - Execute tests and understand test patterns
- [Run Code Coverage](run-coverage.md) - Generate coverage reports and enforce thresholds
- [Run Migrations](run-migrations.md) - Apply database schema migrations

### Production Deployment

- [Deploy to Production](deploy-production.md) - Complete production deployment guide for VPS/dedicated servers
- [Backup and Restore (Production)](backup-restore-production.md) - Production backup strategies and disaster recovery

### Database Operations

- [Backup and Restore Database](backup-restore-database.md) - Development database backup and recovery procedures

### Version Control

- [Commit Changes](commit-changes.md) - Follow the project's commit protocol
- [Manage Git Hooks](manage-git-hooks.md) - Install and configure git hooks

### Documentation

- [Write Domain Documentation](write-domain-docs.md) - Create and maintain domain documentation
- [Maintain READMEs](maintain-readmes.md) - Keep directory READMEs up to date

## How to Use These Guides

1. **Find your task** - Look for the guide that matches what you're trying to do
2. **Follow the steps** - Guides provide specific, actionable instructions
3. **Adapt as needed** - Use your judgment to adapt steps to your situation

When adding new how-to guides:

- Focus on a single task
- Provide step-by-step instructions
- Include examples and expected output
- Link to explanations for "why" details
