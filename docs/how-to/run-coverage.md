# How to Run Code Coverage

This guide explains how to generate and analyze code coverage reports for Quailcomp.

## Quick Start

```bash
# Run all tests with coverage (generates report and enforces 90% threshold)
bun run test:coverage
```

## Understanding Coverage Commands

### Full Coverage Workflow

```bash
bun run test:coverage
```

This runs the complete coverage workflow:

1. Cleans old coverage data
2. Runs tests with coverage in all workspaces
3. Merges LCOV files
4. Generates and displays report
5. Checks 90% threshold

### Individual Workspace Coverage

```bash
# Data client (terminal output)
bun run --cwd data/client test:coverage

# Server (terminal output)
bun run --cwd server test:coverage

# CLI (terminal output)
bun run --cwd cli test:coverage

# Book metadata service
bun run --cwd services/book-metadata test:coverage
```

### Generate LCOV Files

```bash
# Generate LCOV for upload to Codecov
bun run test:coverage:generate
```

## Coverage Output Formats

### Terminal Output (Text)

Default for workspace-level commands. Shows:

- File-by-file coverage percentages
- Function coverage
- Line coverage
- Uncovered line numbers

### LCOV Format

Generated by `test:coverage:generate`. Used for:

- Uploading to Codecov
- Integration with IDEs
- Coverage visualization tools

Located at: `coverage/lcov.info` (merged) and `<workspace>/coverage/lcov.info` (individual)

## Coverage Threshold

Quailcomp enforces a **90% coverage threshold** for both:

- Line coverage
- Function coverage

### Threshold Configuration

Configured in `bunfig.toml`:

```toml
[test]
coverageThreshold = 0.9  # 90%
```

### What Happens When Below Threshold

- `bun run test:coverage` exits with code 1
- CI/CD pipeline fails
- Coverage report shows which files are below threshold

## Excluded Files

The following are excluded from coverage:

- Test files (`*.test.ts`, `*.spec.ts`)
- Scripts (`scripts/**`)
- Database migrations (`migrations/**`)
- Setup/teardown scripts
- Generated files (`domains/types/**`)
- Node modules
- Build output
- Frontend (uses different coverage approach)

See `bunfig.toml` for complete exclusion list.

## Viewing Coverage in CI/CD

Coverage is automatically uploaded to Codecov on every push/PR.

View coverage:

1. Go to [codecov.io/gh/USERNAME/quailcomp](https://codecov.io/gh/USERNAME/quailcomp)
2. Browse file-by-file coverage
3. See coverage trends over time
4. View PR coverage diffs

## Troubleshooting

### Coverage files not found

```bash
# Clean and regenerate
bun run test:coverage:clean
bun run test:coverage:generate
```

### Threshold failures

Check which files are below 90%:

```bash
bun run test:coverage:report
```

### Workspace coverage missing

Ensure workspace has tests:

```bash
# Check for test files
ls <workspace>/tests/*.test.ts
```
